    Notes de version

    Mémo de synthèse

    1. Ouvrez Claude, ChatGPT ou Grok (prompt déjà saisi), ou « Copier le prompt » pour une autre IA.
    2. Joignez les PDF puis envoyez.
    3. Collez la réponse ci-dessous et générez le mémo PDF (1 à 2 pages).

    Sans réponse d'IA, le mémo reprend uniquement le contexte et les points détectés automatiquement.

    Approfondir avec une IA

    1. Ouvrez Claude, ChatGPT ou Grok : le prompt est déjà saisi (et copié). Pour une autre IA, utilisez « Copier le prompt » et collez-le.
    2. Joignez les PDF avant d'envoyer — un lien ne peut pas transporter de fichiers.
    3. Copiez toute la réponse de l'IA et collez-la dans le cadre du bas, puis « Importer ».
